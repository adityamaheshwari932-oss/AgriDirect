# Data Flow Diagrams (DFD)

**Project:** AgriDirect  
**Status:** 🔴 Draft — to be completed during Phase 0–1

---

## Purpose

This folder contains Data Flow Diagrams that describe how data moves through the AgriDirect system — between actors, processes, and data stores.

## DFD Levels

| Level | Description |
|---|---|
| Level 0 (Context) | Single-process diagram showing system boundary and all external entities |
| Level 1 | Major processes decomposed from the context diagram |
| Level 2+ | Further decomposition of complex processes as needed |

## Format

Diagrams will be written in **Mermaid** syntax (renderable in GitHub and compatible markdown viewers) with a written narrative for each process.
